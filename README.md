# Controle Financeiro

Sistema de controle financeiro desenvolvido em **Python**, com o objetivo de praticar conceitos de programação e criar uma aplicação para gerenciamento de movimentações financeiras.

O sistema permite **cadastrar receitas**, informando valor, descrição e categoria, e armazena os dados em um arquivo **JSON** para que as informações sejam persistidas.

### Funcionalidades planejadas

- Adicionar receitas
- Adicionar despesas
- Listar movimentações
- Consultar saldo
- Gerar relatórios financeiros
- Armazenar dados em JSON
- Validação dos dados inseridos

O projeto está sendo desenvolvido de forma incremental, com novas funcionalidades sendo adicionadas conforme o aprendizado em **Python, orientação a objetos, manipulação de arquivos e estruturas de dados**.
